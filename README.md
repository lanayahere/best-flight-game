Sunset Courier is a 3D bush-flying game over Amber Valley at golden hour: fly the Kestrel through glowing target rings, nurse the fuel, and bring her home to Marigold Field. It has a lift-and-stall flight model with flaps and gear, three missions (Ring Rally, Bush Landing, timed Courier Run), a chase/cockpit camera, a live HUD with lit instruments, and synthesised WebAudio engine and wind — all offline, in one static game/ folder.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080/ in desktop Chrome. Arrow keys fly, W/S work the throttle, F flaps, G gear, C switches to the cockpit, P pauses, R resets, M mutes.
